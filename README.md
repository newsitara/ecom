# Sitara Atelier — E-Commerce Under Construction & Launching Soon Page

A boutique, interactive "Under Construction / Launching Soon" page for **Sitara Atelier**. Designed with a warm aesthetic palette (cream, espresso, terracotta, champagne gold, sage) and cute micro-interactions.

## ✨ Features
- **Cute Animated SVG Mascot**: Bouncing boutique tote bag with blinking eyes and joyful click animations.
- **Interactive Sparkles**: Real-time click starburst effects.
- **Atelier Roadmap**: Visual construction progress tracker.
- **VIP Waitlist System**: Email subscription with celebration confetti and an exclusive 15% discount ticket reveal.
- **Live Countdown Timer**: Responsive launch counter.
- **Zero Heavy Frameworks**: Pure HTML5, CSS3, and modern vanilla JavaScript.

## 🚀 Getting Started
Simply open `index.html` in any modern web browser or serve with any static web server (e.g. `npx serve` or GitHub Pages).
